# ソウブレイズex × 闘タイプ 複合デッキ 対戦戦略

## デッキコンセプト

**序盤はソルロック＋ルナトーンの闘タイプ軸、終盤はソウブレイズexのしんえんほむらで高火力を出す「二段構えデッキ」。**

ルナトーンのルナサイクル特性で闘エネルギーをトラッシュしながら手札を補充し、同時にパーフェクトミキサーなどで炎エネルギーもトラッシュに送る。トラッシュの炎エネが溜まったタイミングでソウブレイズexにシフトし、しんえんほむらで大ダメージを狙う。

## 攻撃技の性能

### コスモビーム（ソルロック）
- **必要エネルギー**: 闘×1
- **ダメージ**: 70（弱点・抵抗力を計算しない）
- **条件**: 自分のベンチに「ルナトーン」がいないと失敗
- 安定した固定70ダメージ。弱点・抵抗力無視のため安定して削れる

### しんえんほむら（ソウブレイズex）
- **必要エネルギー**: 炎×1
- **ダメージ**: 30 + トラッシュの炎エネルギー枚数 × 20
- 炎エネが3枚トラッシュで90（コスモビームを超える）、6枚で150

> **切り替えしきい値**: `trash_fire >= 3` でソウブレイズexを優先アタッカーに切り替える

## フェーズ別戦略

### フェーズ1：序盤（炎エネトラッシュ < 3枚）

**目標**：ソルロックでバトル、ルナサイクルでドロー加速、エネルギーをトラッシュに貯める

1. バトル場：**ソルロック**（コスモビーム担当）
2. ベンチ：**ルナトーン**（ルナサイクル使用に必須）、カルボウを並べる
3. ルナサイクルで闘エネをトラッシュ→3枚ドロー
4. モグリューをベンチに出すと**ほりまくり**が発動→闘エネを3枚まとめてトラッシュ
5. パーフェクトミキサーで炎エネも積極的にトラッシュ

### フェーズ2：後半（炎エネトラッシュ >= 3枚）

**目標**：ソウブレイズexにシフトしてしんえんほむらで高火力

1. カルボウをソウブレイズexに進化させてバトル場へ
2. 炎エネルギーをソウブレイズexに1枚つけて攻撃
3. しんえんほむら：炎エネ3枚で90、4枚で110、6枚で150（弱点なら2倍）

## ルナサイクル使用ロジック

ルナトーンの特性「ルナサイクル」は **ソルロックが場にいる** ことが条件。

| 状況 | 行動 |
|---|---|
| バトル場のソルロックに闘エネ0枚 ＋ 手札の闘エネが1枚だけ | **使わない**（エネルギーをソルロックに付与して攻撃） |
| バトル場のソルロックに闘エネ0枚 ＋ 手札の闘エネが2枚以上 | **使う**（1枚トラッシュ後、残り1枚をソルロックに付与） |
| ソルロックにすでに闘エネがついている | **使う**（攻撃準備は完了しているので積極ドロー） |
| ソルロックがベンチにいる | **使う** |

## エネルギー付与方針

| エネルギー種 | 付与先 | 優先度 |
|---|---|---|
| 炎・闘エネルギー | バトル場の非アタッカー（逃げるコスト） | 最高（8800） |
| 基本炎エネルギー | ソウブレイズex（炎エネ0枚のとき） | 高（8010） |
| 基本闘エネルギー | ソルロック（ルナトーンがベンチにいる場合） | 高（8000） |
| ミストエネルギー | 通常時は低優先（500〜1500） | 低 |
| ミストエネルギー | **相手にケーシィライン確認時 → ソウブレイズexに最優先** | **特殊（下記参照）** |

**ソウブレイズexのエネルギーは炎×1枚のみ**。しんえんほむらは炎×1で使えるため、余分につけない。

## ミストエネルギーの特殊運用：ケーシィライン対策

相手の場またはベンチに **ケーシィ（109/741）・ユンゲラー（742）・フーディン（245/743）** が確認された場合、ミストエネルギーをソウブレイズexに付けることを最優先で行う。

> **理由**：ミストエネルギーは「このカードをつけているポケモンは、相手のポケモンが使うワザの効果を受けない」。フーディンなどのワザ効果（ダメカン移動など）からソウブレイズexを保護する。

| ソウブレイズexの状態 | スコア | 動作 |
|---|---|---|
| 炎エネ1枚以上つき（攻撃可能）＋ミストなし | **10500**（全行動中で最高） | 即座にミストエネルギーを付与（進化10000+より高い） |
| 炎エネ0枚（攻撃不可）＋ミストなし | 7900 | 炎エネ付与（8010）が先に行われ、翌ターンにミスト付与 |
| ミストエネルギーがすでにある | 対象外 | 二重付与しない |
| 相手にケーシィラインがいない | 200（低優先） | 通常の優先度 |

## ボスの指令 使用条件

以下のいずれかを満たす場合に使用（スコア3200）：

1. **相手ベンチのexポケモンをOHKOできる場合**
2. **バトル場をOHKOできない場合に限り**、以下の条件を満たす非exポケモン：
   - 対戦中にアクティブとして登場したことがある（攻撃してきたアタッカー）
   - 現在エネルギーを1枚以上持っている

## トラッシュ選択の方針

### ハイパーボールなどのコスト（手札からトラッシュ）
優先度（高→低）：
1. **炎エネルギー**（200）：しんえんほむら火力に直結
2. **闘エネルギー**（180）：ルナサイクルで使うが比較的余りやすい
3. その他グッズ・サポート（50）
4. **ソルロック・ルナトーン・カルボウ・ソウブレイズex**（-100）：絶対温存
5. **探検家の先導・夜のタンカ**（-50）：温存
6. **ドロー系サポート（リーリエ・ゼイユ）**：ベンチ未展開 or エネルギーが手札にない場合は -100 で温存

### パーフェクトミキサー・モグリューのほりまくり（山札からトラッシュ）
- **炎エネルギー・闘エネルギー**：優先してトラッシュ（200）
- その他のカード：絶対に捨てない（-200）

### バトル場（優先度順）
1. **ソルロック**（コスモビームで即戦力）
2. **カルボウ**（ソウブレイズexへ進化）

3. **カルボウ**（ソウブレイズexの進化元）
4. **モグリュー**（ほりまくりで闘エネをトラッシュ）
5. **キチキギスex**（KO後のドロー保険）
